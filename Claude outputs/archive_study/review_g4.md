## Habits not in the rules
- **Elevation tags everywhere:** 3-box tags (T / B / HT) at slabs, every beam end and drop panel; slab thickness written beside the box. 2019 sheets use unlabelled boxes (1071) or T:/B:/HT = (1080); 2023 sheets add column tags "22X22 COL / … / COL HT" (1226).
- **Size labels instead of dims:** beams "16-18X36 BM", "22/24 x 34 (@ 59'-0")"; column sizes "24" / 16"" beside each column.
- **Notes instead of dims:** "BEAMS … CENTERED ON GRID U.N.O.", "SLAB EDGE VARIES … MATCH PH1", "SOFFIT STEP FOLLOWS AROUND FACE OF COL, TYP", "DECK EDGE FORM IS 8" TALL", "1/2" GAP", "SHAFT OPNG", "TEMPORARY SLAB OPENING FOR CRANE".
- **Openings:** X across the hole (often magenta/red), "OPENING"/"OPNG"/"(R.O.)" labels; shaft sizes written inside.
- **Enlarged core plans** on the same sheet with a dashed callout box (1226) — the main plan then skips core detail.
- **Drop panels** dimensioned half-each-side of the column centre (5'-0" | 5'-0").
- **CJs/closure strips** shown with "CJ" in the line, red "CONSTRUCTION JOINT", or hatched "28 DAY DELAY CLOSURE STRIP"; pour labels "POUR-5".
- **Colour:** magenta revision clouds, red CJ/depression hatch, orange highlighted beam, blue revised text, red review markups (1071).
- **Overall strings labelled** with street/adjacent names (ALLEY, TERRY AVE, EXISTING BUILDING); partial overalls between main string and total (1080).
- **Section / detail markers** heavily used (every beam bay on 1119/1234/1115).
- **Older vs newer:** 2019 sheets (1071, 1080) are the most densely dimensioned with many small sleeves; 2023 sheets (1234, 1226) rely more on "centred on grid" notes, tags and enlarged plans. Chain-vs-stack choice varies by detailer, not by year.
