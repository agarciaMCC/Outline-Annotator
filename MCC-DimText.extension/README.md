# MCC Dim Text - pyRevit extension

Adds an "MCC" tab to Revit with a single button, Dim Text, for batch-editing
dimension prefix/suffix text (e.g. "R.O.") and overriding unknown dimensions.

## Install
1. Install pyRevit (free): https://github.com/pyrevitlabs/pyRevit/releases
2. Unzip this file somewhere permanent, e.g. C:\Users\<you>\Documents\pyRevit\
   You should end up with ...\pyRevit\MCC-DimText.extension\
3. In Revit: pyRevit tab > Settings > Custom Extension Directories > Add
   and pick the folder that CONTAINS MCC-DimText.extension (e.g. ...\Documents\pyRevit).
4. Save Settings, then click Reload on the pyRevit tab.
5. The MCC tab appears with the Dim Text button.
